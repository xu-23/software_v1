- 单位移动和攻击仍为即时表现，没有逐格动画。

- 图鉴使用单位名称缩写占位头像，没有正式美术资源。
- 当前电脑没有 Godot 4.7.2 Export Templates，未生成独立 Windows EXE。
- 技术检查完成后仍需人类实际游玩并评价平衡、地图节奏和操作感受。
