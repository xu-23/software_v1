# chess in war v0.1.1 最终形态报告

## 完成结论

v0.1.1 已在 v0.1.0 战斗闭环上完成操作与反馈强化。核心地图、数值和战斗规则保持不变，新增功能均位于控制器状态与 UI 表现层。

自动化测试共 46 项，全部通过；Windows Godot 编辑器导入、主场景启动、图形运行与 1100x720 截图检查通过。

## 新增功能

| 功能 | 最终状态 |
|---|---|
| 战斗日志 | 显示最近 8 条回合、移动、攻击、待机与结算事件 |
| 悬停信息 | 显示格子、地形、高度、移动消耗、通行性和单位状态 |
| 路径预览 | 可达格显示最小消耗路径，HUD 显示路径成本 |
| 取消状态 | 攻击选择取消后保留单位并返回移动或行动状态 |
| 最近行动 | 地图显示最近移动路径或攻击连线与目标框 |
| 敌方播放 | 敌人按 ID 逐个刷新，默认单位间隔 0.35 秒 |
| 输入锁定 | 敌方回合中拒绝玩家选择和操作 |
| 重开隔离 | generation 使旧异步回合不能修改新战斗 |

## 保留功能

- 10x10 地图、平地、森林、水域规则、山体与高度系统。
- 河流移动加耗与悬崖移动/近战阻挡。
- 两名玩家单位、三名敌人及原有数值和出生点。
- 加权移动、友军穿越、敌军阻挡。
- 近战、远程、高差射程、护盾与真实伤害。
- 玩家/敌方回合、AI、死亡、Victory 和 Defeat。
- JSON 数据加载、数据校验和错误报告。
