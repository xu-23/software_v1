# chess in war v0.1.2 规则参考

## 回合与操作

- 玩家与敌方轮流行动；玩家可按任意顺序操作存活且尚未行动的单位。
- 单位在回合开始时获得等于 `move_range` 的移动点，可分多段移动。
- 每段移动立即扣除实际最低成本；攻击、待机或手动结束回合会清空未使用移动点。
- 单位攻击或待机后结束本回合行动。击败全部敌人即 Victory，玩家全部阵亡即 Defeat。
- `Menu > Restart` 重开当前关卡；`Menu > Levels` 放弃当前进度并返回关卡选择。

## 移动规则

棋盘仅允许上下左右移动。友军格可经过但不可停留，敌军格不可经过或停留。高度不增加或减少移动成本。

| 目标地形 | 可通行 | 进入条件 | 移动消耗 | 高度 |
|---|---|---|---|---:|
| Plain | 是 | 剩余至少 1 | 1 | 0 |
| Forest | 是 | 剩余至少 2 | 2 | 1 |
| Swamp | 是 | 剩余至少 2 | 全部剩余移动点 | 0 |
| Water | 否 | 不可进入 | - | 0 |
| Mountain | 否 | 不可进入 | - | 10 |

| 边界 | 移动 | 近战 | 远程 |
|---|---|---|---|
| Normal | 正常 | 可跨越 | 可跨越 |
| River | 额外消耗 1 | 可跨越 | 可跨越 |
| Cliff | 阻挡 | 阻挡 | 不直接阻挡 |

跨河进入 Plain 或 Forest 时，边界消耗与地形消耗相加。进入 Swamp 时只要进入前至少有 2 点，成功后移动点直接归零。

## 攻击与伤害

- 近战只能攻击曼哈顿距离 1 的敌人，不受高度影响，但不能跨 Cliff。
- 远程只能攻击基础 `attack_range` 内，且目标地形高度不高于攻击者地形高度的敌人。
- 高地不增加远程射程；同高可以攻击，低打高不可攻击。
- 普通伤害优先扣护盾。一次攻击若击碎护盾，剩余伤害不会溢出到 HP；后续攻击才扣 HP。
- `true_damage` 绕过护盾直接扣 HP。当前 v0.1.2 配置中没有单位启用真实伤害。
- HP 降至 0 时单位死亡并离开占格、行动与目标集合。

## 关卡

### Stage 01: First Contact

| 项目 | 内容 |
|---|---|
| 地图 | 10x10，Plain、Forest、Mountain，River 与 Cliff 边界 |
| 玩家出生 | Vanguard `(1,8)`；Archer `(2,8)` |
| 敌方出生 | Raider A `(7,1)`；Raider B `(8,2)`；Marksman `(7,4)` |

### Stage 02: Flooded Pass

| 项目 | 内容 |
|---|---|
| 地图 | 12x12，包含五种地形、River 与 Cliff 边界 |
| 玩家出生 | Vanguard `(1,10)`；Archer `(2,11)`；Ranger `(6,9)` |

两关胜负条件相同：击败全部敌人获胜，全部玩家单位阵亡失败。两关从启动时均可选择，不设解锁、存档或评分。
