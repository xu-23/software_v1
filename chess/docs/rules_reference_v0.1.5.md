# chess in war v0.1.5 规则参考

## 回合与操作

- 玩家与敌方轮流行动；玩家可按任意顺序操作存活且尚未行动的单位。
- 单位每回合恢复 `move_range` 点移动力，可在攻击或待机前分多段移动。
- 攻击、待机或手动结束回合会清空未使用移动力。
- 击败全部敌人即胜利，玩家单位全部阵亡即失败。
- `Menu` 提供 Restart、Levels 和 Encyclopedia；图鉴返回时保留战斗状态。

## 地形、移动与攻击

| 地形 | 通行 | 最低进入移动力 | 成功进入消耗 | 高度 |
|---|---|---:|---|---:|
| Plain/平地 | 是 | 1 | 1 | 0 |
| Forest/森林 | 是 | 2 | 2 | 0 |
| Hill/丘陵 | 是 | 2 | 2 | 1 |
| Swamp/沼泽 | 是 | 2 | 全部剩余移动力 | 0 |
| Water/水域 | 否 | - | - | 0 |
| Mountain/山地 | 否 | - | - | 10 |

棋盘仅允许上下左右移动。友军格可经过但不可停留，敌军格不可经过或停留。River 额外消耗 1；Cliff 阻挡移动和跨边界近战，不直接阻挡远程攻击。

- 近战只能攻击曼哈顿距离 1 的敌人，不受高度影响，但不能跨 Cliff。
- 远程只能攻击基础射程内、目标高度不高于攻击者的敌人；同高和高打低允许，低打高禁止。
- 普通伤害优先扣护盾；一次攻击击碎护盾后，剩余伤害不溢出到 HP。
- 无护盾时普通伤害扣 HP；真实伤害绕过护盾直接扣 HP。

## 特殊能力

- 翠绿卫士/生生不息：每回合第一次停在 Forest 时当前护盾 +2。
- 大地守卫/万物之源：每局第一次停在 Hill 时，有护盾则当前护盾翻倍；零护盾也消耗机会。
- 火焰术士/火烧联营：攻击 Forest 中的单位时伤害乘 2。

## 隐藏机遇

| 机遇 | 底层地形 | 效果 |
|---|---|---|
| 水果 | Forest | 当前 HP +1，不超过最大 HP |
| 精铁 | Hill | 当前护盾 +1 |
| 泥沼 | Swamp | 当前护盾 +1 |
| 补给 | Plain | 当前 HP +2，不超过最大 HP |

- 机遇不显示图标，也不会出现在未触发格的悬停信息中。
- 玩家和敌方都可触发；每次移动按实际路径从起点后的第一格开始逐格检查。
- 中间格和终点均可触发，同一路径可触发多个机遇。
- 触发后立即从本局移除；满 HP 时治疗实际增加 0，机遇仍会消失。
- 机遇不改变地形、移动消耗、高度或 AI 选路。Restart 会恢复关卡初始机遇。
- 触发结果使用中文单位名和机遇名写入战斗日志。

## 敌方 AI

- 当前已有合法目标时，优先攻击低 HP、低护盾目标。
- 无法立即攻击时，比较本回合可达终点到合法攻击位置的实际路线代价。
- 路线遵守 Water、Mountain、Cliff、地形和边界代价；必要时可暂时增加曼哈顿距离。
- AI 沿实际移动路径触发机遇，但不预先感知隐藏机遇并为其改变路线。

## 界面语言与图标

- 百科卡片、战斗侧栏、状态与日志使用中文单位名；敌方级别显示普通/精英。
- JSON 英文标准名称、数值覆盖键和棋盘 A/VG/EW 等缩写保持不变。
- 游戏标题、关卡名、Move/Attack/Wait/End Turn、Menu 和 Encyclopedia 导航保持英文。
- 战士、掠夺者和弓手分别显示剑、马、弓职业角标；弓手显示射程数字。

## 单位数值接口

`data/units/unit_stat_overrides.json` 仍可按英文标准名覆盖 `max_hp`、`shield`、`attack`、`move_range`。v0.1.5 的默认平衡值直接位于基础单位 JSON，覆盖文件默认为空；保存覆盖后需 Restart 或重新进入关卡。
