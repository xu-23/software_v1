## 导出与警告

- Windows Desktop 导出尝试失败：缺少 Godot 4.7.2 的 `windows_debug_x86_64.exe` 与 `windows_release_x86_64.exe` Export Templates。
- 图形运行出现 WASAPI 初始化失败并回退 dummy 音频的警告；当前无音频内容，不影响逻辑与画面。
- 当前未生成独立 Windows EXE，可直接通过 Godot 编辑器运行。

## 已知限制

- 数值覆盖在重新加载关卡时生效，不热更新进行中的单位。
- 第四关使用固定种子，不在每次 Restart 时改变布局。
- 单位移动和攻击仍为即时表现，没有逐格动画和正式角色贴图。
- 战斗进度不保存，返回 Levels 会放弃当前战斗。
- 技术检查完成后仍需人类实际游玩并评价图标辨识度、第四关难度和操作感受。
