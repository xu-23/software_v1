# chess in war v0.1.0 最终形态报告

## 完成结论

v0.1.0 已完成为可在 Windows Godot 4.7.2 中直接运行的单关卡桌面战棋原型。游戏从启动进入战场，支持玩家选择、加权移动、攻击或待机、敌方 AI 回合、单位死亡以及 Victory/Defeat，已形成完整的一局战斗闭环。

自动规则测试 31 项全部通过；编辑器导入、无界面启动、Windows 图形启动和 1100x720 UI 截图检查均通过。

## 最终运行形态

| 项目 | 形态 |
|---|---|
| 入口 | 启动后直接进入唯一战斗关卡 |
| 窗口 | 1100x720，可调整大小 |
| 棋盘 | 10x10 方格，代码绘制占位风格 |
| 单位 | 玩家 2 个、敌方 3 个，蓝红阵营区分 |
| 地形 | 平地、森林、山体；水域规则已配置但本关未放置 |
| 边界 | 河流和悬崖均有独立视觉线条 |
| HUD | 回合、战况、选择单位属性、地形高度、行动按钮 |
| 输入 | 鼠标为主，Esc/右键取消，Space 可待机 |
| 结算 | Victory、Defeat、重新开始 |

界面实测图：`docs/v0.1.0_ui_smoke.png`。

## 已完成系统

- JSON 数据加载、错误报告与启动校验。
- 地形高度、通行性、基础移动消耗和边界查询。
- 加权移动范围、路径回溯、敌军阻挡、友军可穿越不可停留。
- 近战与远程分类、高低差射程、悬崖攻击规则。
- 护盾优先、击碎无溢出、真实伤害和死亡处理。
- 玩家选择、移动、攻击、待机、手动或自动结束回合。
- 敌方按 ID 行动、目标优先级、接近目标、移动后攻击。
- 存活单位胜负检查和战斗锁定。
- 自绘棋盘、地形图形、边界、范围、单位 HP 与护盾反馈。
