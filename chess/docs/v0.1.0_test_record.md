## 发布导出检查

项目已提供 `Windows Desktop` 导出预设，但当前电脑未安装 Godot 4.7.2 导出模板，因此没有生成独立 EXE。Godot 报告缺少：

```text
C:/Users/33995/AppData/Roaming/Godot/export_templates/4.7.2.stable/windows_debug_x86_64.exe
C:/Users/33995/AppData/Roaming/Godot/export_templates/4.7.2.stable/windows_release_x86_64.exe
```

这不影响在 Godot 编辑器中运行 v0.1.0。安装同版本导出模板后，可直接使用现有预设生成 `export/chess-in-war-v0.1.0.exe`。

## 已知限制

- AI 行动没有动画，敌方回合按规则同步完成。
- 当前只有一个关卡和占位棋盘风格。
- 通过 WSL 命令拉起 Windows Godot 时，WASAPI 初始化失败并回退到空音频驱动；v0.1.0 不包含音频，不影响规则与画面。
- UI 冒烟测试验证初始画面和布局，鼠标操作由控制器集成测试与人工运行共同覆盖。
