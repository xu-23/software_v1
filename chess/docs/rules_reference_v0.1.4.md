# chess in war v0.1.4 规则参考

## 回合与操作

- 玩家与敌方轮流行动；玩家可按任意顺序操作存活且尚未行动的单位。
- 单位每回合恢复 `move_range` 点移动力，可在攻击或待机前分多段移动。
- 攻击、待机或手动结束回合会清空未使用移动力。
- 击败全部敌人即胜利，玩家单位全部阵亡即失败。
- `Menu` 提供 Restart、Levels 和 Encyclopedia；图鉴返回时保留战斗状态。

## 战斗界面语言

- 地形名称、通行状态、高度、移动/路径消耗和剩余移动力使用中文。
- 单位阵营、类型、HP、护盾、攻击、移动、射程、坐标、属性和能力使用中文字段。
- 百科卡片标题、战斗侧栏、状态与最近 8 条日志使用中文单位名称。
- JSON 英文标准名称、数值覆盖键和棋盘 A/VG/EW 等缩写保持不变。
- 游戏标题、关卡名、Move/Attack/Wait/End Turn、Menu 和 Encyclopedia 导航保持英文。

## 地形与移动

| 地形 | 通行 | 最低进入移动力 | 成功进入消耗 | 高度 |
|---|---|---:|---|---:|
| Plain/平地 | 是 | 1 | 1 | 0 |
| Forest/森林 | 是 | 2 | 2 | 0 |
| Hill/丘陵 | 是 | 2 | 2 | 1 |
| Swamp/沼泽 | 是 | 2 | 全部剩余移动力 | 0 |
| Water/水域 | 否 | - | - | 0 |
| Mountain/山地 | 否 | - | - | 10 |

棋盘仅允许上下左右移动。友军格可经过但不可停留，敌军格不可经过或停留。River 额外消耗 1；Cliff 阻挡移动和跨边界近战，不直接阻挡远程攻击。

## 攻击与伤害

- 近战只能攻击曼哈顿距离 1 的敌人，不受高度影响，但不能跨 Cliff。
- 远程只能攻击基础射程内、目标高度不高于攻击者的敌人；同高和高打低允许，低打高禁止。
- 普通伤害优先扣护盾。一次攻击击碎护盾后，剩余伤害不溢出到 HP。
- 无护盾时普通伤害扣 HP；真实伤害绕过护盾直接扣 HP。
- 火焰术士（Flamecaster）攻击 Forest 中目标时基础攻击乘 2，再进入护盾/HP 结算。

## 特殊能力

- 翠绿卫士（Verdant Guard）/生生不息：每回合第一次停在 Forest 时当前护盾 +2。
- 大地守卫（Earth Warden）/万物之源：每局第一次停在 Hill 时，有护盾则当前护盾翻倍；零护盾也消耗机会。
- 火焰术士（Flamecaster）/火烧联营：攻击 Forest 中的单位时伤害乘 2。

## 敌方 AI

- 当前已有合法目标时，优先攻击低 HP、低护盾目标。
- 无法立即攻击时，比较本回合可达终点到合法攻击位置的实际路线代价。
- 路线遵守 Water、Mountain、Cliff、地形和边界代价；必要时可暂时增加曼哈顿距离。
- 所有攻击位置不可达时回退到曼哈顿接近规则；不存在有效移动时待机。

## 单位数值接口

`data/units/unit_stat_overrides.json` 可按标准英文单位名覆盖：

- `max_hp`：至少 1。
- `shield`：至少 0。
- `attack`：至少 0。
- `move_range`：至少 0。

不允许修改名称、阵营、类型、职业、射程、真实伤害、属性、能力或资源路径。同名 Raider 的三个定义同步应用。空配置保持上表数值。

保存配置后 Restart、重新进入关卡或重启游戏生效。代码可向 `BattleController.start_new_battle()` 传入同结构覆盖，或调用 `UnitStatOverrides.apply_to_definitions()`。当前战斗单位不热更新。
