### 4.2 工作流

```text
1. 在 WSL 中保存项目源码
2. 使用 VS Code Remote WSL 编辑代码和配置
3. 使用 Windows 版 Godot 打开 WSL 项目路径
4. 在 Godot 中编辑场景、TileMap、UI 和资源
5. 在 Godot 中运行游戏预览
6. 使用 WSL Git 提交代码
7. 推送到 GitHub 进行共同开发
8. 使用 Godot 导出 Windows 桌面版
```

## 8. 数据文件规划

### 8.1 单位数据

文件：

```text
data/units/player_units.json
data/units/enemy_units.json
```

字段：

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识 |
| `name` | 单位名称 |
| `team` | 阵营 |
| `class_id` | 职业 |
| `level` | 等级 |
| `max_hp` | 最大生命 |
| `attack` | 攻击 |
| `defense` | 防御 |
| `move_range` | 移动力 |
| `attack_range` | 攻击距离 |
| `sprite` | 资源路径 |

### 8.2 地图数据

文件：

```text
data/maps/map_001.json
```

字段：

| 字段 | 说明 |
|---|---|
| `id` | 地图标识 |
| `name` | 地图名称 |
| `width` | 宽度 |
| `height` | 高度 |
| `tiles` | 地形数组 |
| `blocked` | 阻挡数据 |

### 8.3 关卡数据

文件：

```text
data/chapters/chapter_001.json
```

字段：

| 字段 | 说明 |
|---|---|
| `id` | 关卡标识 |
| `name` | 关卡名称 |
| `map_id` | 地图标识 |
| `player_spawns` | 玩家出生点 |
| `enemy_spawns` | 敌人出生点 |
| `win_condition` | 胜利条件 |
| `lose_condition` | 失败条件 |

| 项目 | 估算空间 |
|---|---:|
| WSL 基础环境 | 2-5 GB |
| Godot 编辑器 | 100-300 MB |
| 项目源码 | 50-300 MB |
| 美术占位资源 | 100 MB-1 GB |

```text
最低：10-20 GB
舒适：30-50 GB
大量正式资源：50 GB 以上
```

| 场景 | 估算内存 |
|---|---:|
| VS Code Remote WSL | 500 MB-2 GB |
| Godot 编辑器 | 500 MB-2 GB |
| 游戏预览 | 100-500 MB |
| 浏览器、素材工具、其他程序 | 1-4 GB |

建议配置：

```text
8 GB RAM：可做简单原型
16 GB RAM：较舒适
```
