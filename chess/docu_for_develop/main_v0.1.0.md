# chess in war v0.1.0 最小可运行版本游戏规则策划

## 1. 版本定位

| 条目 | 内容 |
|---|---|
| 游戏名称 | chess in war |
| 版本号 | v0.1.0 |
| 游戏类型 | 2D 回合制战棋 |
| 目标平台 | Windows 桌面版 |
| 游戏模式 | 单人离线 |
| 核心目标 | 完成一局可从开始运行到胜负结算的最小战斗闭环 |

v0.1.0 只实现战棋核心规则，不实现剧情、养成、装备、联网、存档和复杂技能。

## 2. 最小可运行目标

v0.1.0 启动后进入一张战斗地图，玩家可以完成以下流程：

```text
进入战斗
-> 选择玩家单位
-> 查看移动范围
-> 移动单位
-> 查看攻击范围
-> 攻击敌人或待机
-> 结束玩家单位行动
-> 敌方单位自动行动
-> 回合循环
-> 触发胜利或失败
-> 显示结算结果
```

## 3. 关卡规则

### 3.1 关卡数量

v0.1.0 只包含 1 个测试关卡。

| 关卡 ID | 关卡名称 | 目标 |
|---|---|---|
| `stage_001` | 初始测试战场 | 验证地图、移动、攻击、回合、AI 和胜负 |

### 3.2 地图规格

| 条目 | 规则 |
|---|---|
| 地图类型 | 正方形方格地图 |
| 地图尺寸 | 10x10 |
| Tile 大小 | 64x64 像素 |
| 坐标原点 | 左上角为 `(0, 0)` |
| X 轴方向 | 向右递增 |
| Y 轴方向 | 向下递增 |
| 是否允许斜向移动 | 不允许 |
| 是否存在高度差 | 存在 |
| 高度单位 | 整数高度 |
| 地块边界系统 | 存在，支持河流与悬崖 |

### 3.3 初始地形

v0.1.0 使用 4 种地形。

| 地形 ID | 名称 | 可通行 | 基础移动消耗 | 高度 |
|---|---|---|---:|---:|
| `plain` | 平地 | 是 | 1 | 0 |
| `forest` | 森林 | 是 | 2 | 1 |
| `water` | 水域 | 否 | 不可通行 | 0 |
| `mountain` | 山体 | 否 | 不可通行 | 10 |

说明：

- 地形高度参与移动与攻击规则。
- 水域和山体不能进入，也不能作为单位停留格。
- 山体用于阻挡路线和提供高度差场景。
- v0.1.0 不再设置地形防御加成，单位防护由护盾系统承担。
- 第一版不实现草地等更多地形。

### 3.4 地块边界规则

地块边界指两个相邻格子之间的边，不占用格子本身。

v0.1.0 支持 3 种边界：

| 边界 ID | 名称 | 是否可通过 | 移动影响 | 攻击影响 |
|---|---|---|---|---|
| `normal` | 普通边界 | 是 | 无额外消耗 | 不阻挡攻击 |
| `river` | 河流 | 是 | 额外消耗 1 点移动力 | 不阻挡攻击 |
| `cliff` | 悬崖 | 否 | 不可通过 | 阻挡近战攻击，不阻挡远程攻击 |

边界规则：

- 边界只存在于上下左右相邻格之间。
- 单位从一个格子移动到相邻格时，需要同时检查目标地形和两格之间的边界。
- 河流边界可以通过，但进入目标格时额外消耗 1 点移动力。
- 悬崖边界不能通过。
- 近战单位不能隔着悬崖攻击。
- 远程单位可以隔着悬崖攻击，但仍需要满足攻击距离和高度规则。

| 边界 ID | 两侧格子 | 类型 |

## 5. 单位规则

### 5.0 单位类型

v0.1.0 区分近战与远程两类单位。

| 单位类型 | 攻击距离规则 | 基础说明 |
|---|---|---|
| `melee` | 攻击距离只能为 1 | 近身攻击单位 |
| `ranged` | 攻击距离为 1 及以上 | 远程攻击单位 |

类型规则：

- 近战单位的攻击距离固定为 1。
- 远程单位的攻击距离必须大于等于 1。
- v0.1.0 中远程单位默认攻击距离为 2。
- 单位类型不影响移动规则，但影响跨悬崖攻击规则。

### 5.1 玩家单位

| 单位 ID | 名称 | 类型 | 职业 | HP | 护盾 | 攻击 | 移动力 | 攻击距离 | 真实伤害 |
|---|---|---|---|---:|---:|---:|---:|---:|---|
| `player_001` | Vanguard | `melee` | Soldier | 18 | 6 | 6 | 4 | 1 | 否 |
| `player_002` | Archer | `ranged` | Archer | 14 | 3 | 4 | 4 | 2 | 否 |

### 5.2 敌方单位

| 单位 ID | 名称 | 类型 | 职业 | HP | 护盾 | 攻击 | 移动力 | 攻击距离 | 真实伤害 |
|---|---|---|---|---:|---:|---:|---:|---:|---|
| `enemy_001` | Raider A | `melee` | Raider | 10 | 3 | 4 | 3 | 1 | 否 |
| `enemy_002` | Raider B | `melee` | Raider | 10 | 3 | 4 | 3 | 1 | 否 |
| `enemy_003` | Marksman | `ranged` | Archer | 12 | 2 | 3 | 3 | 2 | 否 |

### 5.3 单位状态

每个单位运行时至少包含以下状态：

| 状态 | 说明 |
|---|---|
| 当前 HP | 小于等于 0 时死亡 |
| 当前护盾 | 大于 0 时优先承受非真实伤害 |
| 当前坐标 | 单位所在格子 |
| 是否已移动 | 本回合是否完成移动 |
| 是否已行动 | 本回合是否完成攻击或待机 |
| 是否死亡 | 死亡后从地图移除 |
| 是否拥有真实伤害 | 真实伤害直接作用于 HP，不消耗护盾 |

### 5.4 占格规则

- 每个格子最多只能有 1 个单位。
- 单位不能移动到敌方占据格。
- 单位不能移动到友方占据格。
- 单位不能穿越敌方占据格。
- v0.1.0 默认允许路径穿越友方占据格，但不能停留在友方占据格。

### 5.5 高度相关规则

单位所在高度由当前格子的地形高度决定。

高度规则：

- 平地高度为 0。
- 森林高度为 1。
- 山体高度为 10，但山体不可通行，单位不能站在山体上。
- v0.1.0 不设置单位自身高度。
- 高度差会影响移动消耗与远程攻击距离。

## 6. 回合规则

### 6.1 回合顺序

回合按照以下顺序循环：

```text
玩家回合
-> 敌方回合
-> 玩家回合
```

### 6.2 玩家回合

玩家回合开始时：

- 所有存活玩家单位的 `是否已移动` 设为否。
- 所有存活玩家单位的 `是否已行动` 设为否。

玩家可以选择任意未行动的玩家单位进行操作。

每个单位每回合最多执行：

```text
移动 1 次
+ 攻击或待机 1 次
```

单位完成攻击或待机后，标记为已行动。

### 6.3 敌方回合

敌方回合开始时：

- 所有存活敌方单位的 `是否已移动` 设为否。
- 所有存活敌方单位的 `是否已行动` 设为否。

敌方单位按单位 ID 顺序行动：

```text
enemy_001
-> enemy_002
-> enemy_003
```

所有存活敌方单位完成行动后，回到玩家回合。

### 6.4 结束回合

v0.1.0 支持两种玩家回合结束方式：

- 所有玩家单位均已行动后自动结束回合。
- 玩家点击“结束回合”按钮手动结束回合。

手动结束回合时，未行动玩家单位直接跳过本回合。

| 按键 | 效果 |
|---|---|
| `Esc` | 取消选择或关闭菜单 |
| `Space` | 待机或确认 |

键盘快捷键不是 v0.1.0 的必需功能。

玩家选择单位后的状态流：

```text
未选择
-> 选中玩家单位

-> 点击移动目标
-> 单位移动
-> 显示行动菜单

-> 回到未选择
```

如果选中单位已经行动，则只显示单位信息，不允许移动或攻击。

## 8. 移动规则

### 8.1 移动范围

移动范围由 BFS 计算。

可移动格必须满足：

- 在地图边界内。
- 地形可通行。
- 当前格与目标格之间的边界可通过。
- 总移动消耗不超过单位移动力。
- 目标格未被任何单位占据。

移动消耗：

```text
单步移动消耗 = 目标格基础移动消耗 + 高度差消耗 + 边界额外消耗
```

高度差消耗：

```text
高度差 = 目标格高度 - 当前格高度
如果高度差 <= 0，高度差消耗 = 0
如果高度差 > 0，高度差消耗 = 高度差
```

边界额外消耗：

| 边界 | 额外消耗 |
|---|---:|
| 普通边界 | 0 |
| 河流 | 1 |
| 悬崖 | 不可通过 |

示例：

```text
从平地高度 0 进入森林高度 1：
消耗 = 森林基础消耗 2 + 上坡高度差 1 + 普通边界 0 = 3

从森林高度 1 进入平地高度 0：
消耗 = 平地基础消耗 1 + 下坡高度差 0 + 普通边界 0 = 1

从平地跨河流进入平地：
消耗 = 平地基础消耗 1 + 高度差 0 + 河流 1 = 2
```

### 8.2 移动路径

实际移动路径由 A* 或 BFS 回溯路径计算。

路径规则：

- 只允许上、下、左、右四方向移动。
- 不能穿越不可通行地形。
- 不能穿越悬崖边界。
- 不能穿越敌方单位。
- 可以穿越友方单位，但不能停在友方单位所在格。

### 8.3 移动后规则

单位移动完成后：

- 单位坐标更新为目标格。
- 单位标记为已移动。
- 显示行动菜单。
- 玩家可选择攻击或待机。

v0.1.0 不支持移动后撤销。

## 9. 攻击规则

### 9.1 攻击范围

基础攻击距离按曼哈顿距离计算：

```text
距离 = abs(攻击方 x - 目标 x) + abs(攻击方 y - 目标 y)
```

近战攻击规则：

- 近战单位攻击距离只能为 1。
- 近战攻击不能隔着悬崖边界。
- 近战攻击不受高度差影响。

远程攻击规则：

- 远程单位攻击距离为 1 及以上。
- v0.1.0 远程单位默认攻击距离为 2。
- 远程攻击可以隔着悬崖边界。
- 远程攻击受高度差修正。

远程高度修正规则：

```text
高度差 = 攻击方所在地形高度 - 目标所在地形高度
如果高度差 > 0，有效攻击距离 = 基础攻击距离 + 1
如果高度差 = 0，有效攻击距离 = 基础攻击距离
如果高度差 < 0，有效攻击距离 = max(基础攻击距离 - 1, 1)
```

当曼哈顿距离小于等于有效攻击距离时，可以攻击。

### 9.2 攻击目标

攻击目标必须满足：

- 目标为敌对阵营。
- 目标未死亡。
- 目标在攻击范围内。
- 攻击路径满足单位类型对应的边界和高度规则。

### 9.3 伤害公式

v0.1.0 使用确定性伤害：

```text
基础伤害 = 攻击方攻击
```

非真实伤害结算：

```text
如果受击方当前护盾 > 0：
    护盾承受本次全部攻击
    新护盾 = max(当前护盾 - 基础伤害, 0)
    即使本次攻击击碎护盾，溢出伤害也不作用于 HP
否则：
    受击方 HP = 受击方 HP - 基础伤害
```

真实伤害结算：

```text
如果攻击带有真实伤害效果：
    受击方 HP = 受击方 HP - 基础伤害
    受击方护盾不变化
```

v0.1.0 默认所有单位均无真实伤害。真实伤害字段保留，用于后续技能或特殊单位。

### 9.4 死亡规则

单位受到伤害后：

- 如果有护盾且受到非真实伤害，当前护盾优先减少。
- 如果护盾被击碎，本次攻击的溢出量不减少 HP。
- 如果没有护盾，当前 HP 减少攻击方攻击值。
- 如果受到真实伤害，当前 HP 直接减少攻击方攻击值。
- 当前 HP 小于等于 0 时死亡。
- 死亡单位从地图上移除。
- 死亡单位不再参与行动、寻路、攻击和胜负判断。

### 9.5 暂不实现内容

v0.1.0 不实现：

- 命中率
- 暴击
- 反击
- 武器克制
- 技能
- 范围攻击
- 治疗
- Buff/Debuff
- 护盾恢复
- 护盾击碎特效

## 10. 敌方 AI 规则

### 10.1 AI 行动流程

每个敌方单位行动时执行：

```text
1. 如果敌方单位死亡，跳过。
2. 查找所有存活玩家单位。
3. 如果当前已有可攻击目标，攻击优先目标。
4. 如果当前没有可攻击目标，计算移动范围。
5. 选择移动后最接近优先目标的可移动格。
6. 移动到该格。
7. 如果移动后有可攻击目标，则攻击。
8. 如果移动后仍无可攻击目标，则待机。
```

### 10.2 目标优先级

AI 目标选择规则：

```text
优先攻击当前 HP 最低的可攻击玩家单位
如果 HP 相同，优先攻击当前护盾最低的单位
如果护盾也相同，攻击距离最近的单位
如果仍相同，按单位 ID 字典序选择
```

### 10.3 移动目标选择

当无法直接攻击时：

```text
优先向距离最近的玩家单位靠近
```

移动目标格选择规则：

- 在自身可移动范围内。
- 目标格可停留。
- 移动后到最近玩家单位的曼哈顿距离最小。
- 如果距离相同，选择移动消耗更低的格子。
- 如果仍相同，按坐标排序选择，先比较 y，再比较 x。

## 12. 胜负规则

### 12.1 胜利条件

当所有敌方单位死亡时，玩家胜利。

显示：

```text
Victory
```

### 12.2 失败条件

当所有玩家单位死亡时，玩家失败。

显示：

```text
Defeat
```

### 12.3 胜负判定时机

胜负判定在以下时机执行：

- 任意单位死亡后。
- 玩家回合结束前。
- 敌方单位行动结束后。
- 敌方回合结束前。

一旦触发胜利或失败：

- 停止回合推进。
- 禁止继续选择和行动。
- 显示结算提示。

## 13. 数据配置规则

v0.1.0 使用 JSON 管理关卡和单位基础数据。

### 13.1 文件清单

```text
data/units/player_units.json
data/units/enemy_units.json
data/maps/map_001.json
data/chapters/chapter_001.json
```

### 13.2 单位数据字段

单位数据至少包含：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | String | 单位唯一标识 |
| `name` | String | 单位显示名称 |
| `team` | String | `player` 或 `enemy` |
| `unit_type` | String | `melee` 或 `ranged` |
| `class_id` | String | 职业标识 |
| `max_hp` | int | 最大生命值 |
| `shield` | int | 初始护盾值 |
| `attack` | int | 攻击值 |
| `move_range` | int | 移动力 |
| `attack_range` | int | 攻击距离 |
| `true_damage` | bool | 是否造成真实伤害 |
| `sprite` | String | 单位显示资源路径 |

v0.1.0 不使用 `defense` 字段。

### 13.3 地图数据字段

地图数据至少包含：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | String | 地图唯一标识 |
| `name` | String | 地图显示名称 |
| `width` | int | 地图宽度 |
| `height` | int | 地图高度 |
| `tiles` | Array | 地形二维数组 |
| `tile_defs` | Object | 地形定义，包含可通行、移动消耗、高度 |
| `edges` | Array | 地块边界定义 |

边界数据至少包含：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | String | 边界唯一标识 |
| `a` | Vector2i | 边界一侧格子 |
| `b` | Vector2i | 边界另一侧格子 |
| `edge_type` | String | `normal`、`river` 或 `cliff` |

### 13.4 关卡数据字段

关卡数据至少包含：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | String | 关卡唯一标识 |
| `name` | String | 关卡显示名称 |
| `map_id` | String | 地图标识 |
| `player_spawns` | Object | 玩家单位出生点 |
| `enemy_spawns` | Object | 敌方单位出生点 |
| `win_condition` | String | 胜利条件 |
| `lose_condition` | String | 失败条件 |

### 13.5 数据校验

启动关卡时需要校验：

- 地图宽高有效。
- 地形 ID 均存在。
- 地形高度为整数。
- 地块边界两端坐标必须相邻。
- 地块边界类型必须存在。
- 出生点在地图边界内。
- 出生点可通行。
- 出生点没有重复。
- 单位 HP 大于 0。
- 单位护盾大于等于 0。
- 单位攻击大于等于 0。
- 单位移动力大于等于 0。
- 单位攻击距离大于等于 1。
- 近战单位攻击距离必须等于 1。
- 远程单位攻击距离必须大于等于 1。

如果数据无效，控制台输出错误信息，并阻止进入战斗。
