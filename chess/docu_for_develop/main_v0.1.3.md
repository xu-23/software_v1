## 4. 单位名称与实例 ID

### 4.1 规则

- `name` 是单位模板的唯一标准。
- `id` 只标识关卡中的具体实例和出生点，不代表不同模板。
- 同名单位允许拥有多个不同 ID。
- 同名定义的 `team`、`unit_type`、`class_id`、HP、基础护盾、攻击、移动、射程、真实伤害、特殊属性、能力和头像路径必须完全一致。
- 战斗中的 HP、护盾、位置、移动点与能力触发记录是运行时状态，不参与同名定义一致性比较。
- 数据校验发现同名静态属性不一致时阻止关卡启动。
- 百科按 `team + name` 去重，同名 Raider 只展示一个模板条目。

### 4.2 兼容调整

`enemy_001`、`enemy_002`、`enemy_004` 的显示名称统一为 `Raider`，其静态属性保持一致。原有单位 ID 和关卡出生点不变。

## 5. 地形与边界定义

### 5.1 地形

| ID | 名称 | 通行 | 最低进入移动力 | 消耗 | 高度 |
|---|---|---|---:|---|---:|
| `plain` | Plain | 是 | 1 | 1 | 0 |
| `forest` | Forest | 是 | 2 | 2 | 0 |
| `hill` | Hill | 是 | 2 | 2 | 1 |
| `swamp` | Swamp | 是 | 2 | 全部剩余移动力 | 0 |
| `water` | Water | 否 | - | - | 0 |
| `mountain` | Mountain | 否 | - | - | 10 |

- Forest 从 v0.1.2 的高度 1 修改为高度 0。
- Hill 是 v0.1.3 新增地形，拥有独立颜色和棋盘图案。
- Forest/Hill 进入条件由基础消耗 2 自然保证，并显式保存 `minimum_entry_points: 2`。
- Mountain 保留为不可通行障碍，不替代 Hill。
- 高度继续只影响远程攻击资格，不增加移动消耗。

### 5.2 边界地形

| ID | 名称 | 移动 | 近战 | 远程 |
|---|---|---|---|---|
| `normal` | Normal | 正常 | 可跨越 | 可跨越 |
| `river` | River | 额外消耗 1 | 可跨越 | 可跨越 |
| `cliff` | Cliff | 不可跨越 | 不可跨越 | 不直接阻挡 |

## 6. 特殊属性与能力

单位增加：

| 字段 | 类型 | 说明 |
|---|---|---|
| `special_attribute` | String | `none`、`wood`、`fire`、`earth` |
| `ability_id` | String | 无能力为空字符串，否则引用能力定义 |
| `turn_triggered_abilities` | Dictionary | 当前回合已触发能力 |
| `battle_triggered_abilities` | Dictionary | 本局已触发能力 |

没有特殊属性时，UI 与百科显示 `None`。

### 6.1 生生不息

| 条目 | 规则 |
|---|---|
| 特殊属性 | 木 `wood` |
| 触发 | 每回合第一次完成一次移动且终点为 Forest |
| 效果 | 当前护盾 `+2`，即使进入前护盾为 0 |
| 限制 | 同回合后续进入 Forest 不再触发；下回合可再次触发 |

- 一次多格路径只按最终停留格触发，不按路径中经过的 Forest 触发。
- 玩家与 AI 共用同一地形进入效果接口。

### 6.2 火烧联营

| 条目 | 规则 |
|---|---|
| 特殊属性 | 火 `fire` |
| 触发 | 攻击目标当前站在 Forest |
| 效果 | 本次伤害值为基础攻击的 2 倍 |
| 限制 | 目标不在 Forest 时倍率为 1 |

- 倍率在护盾/HP 结算前计算。
- 护盾击碎无溢出规则保持不变。
- 玩家与 AI 攻击使用同一倍率接口；攻击结果记录 `damage_multiplier`。

### 6.3 万物之源

| 条目 | 规则 |
|---|---|
| 特殊属性 | 土 `earth` |
| 触发 | 每局第一次完成一次移动且终点为 Hill |
| 效果 | 若当前护盾大于 0，则当前护盾翻倍 |
| 限制 | 每局只检查一次；当次护盾为 0 也会消耗触发机会 |

Restart 或重新进入关卡会创建新单位并恢复本局触发机会。

## 8. Encyclopedia

### 8.1 入口与导航

- 战斗 Menu 新增 `Encyclopedia`，现有 Restart/Levels 保留。
- 选择 Encyclopedia 后打开全屏百科视图，当前战斗状态不丢失。
- `Back` 返回进入百科前的战斗视图。
- 百科打开期间隐藏棋盘并阻止棋盘输入；不会修改单位选择、回合或关卡数据。
- 敌方异步回合不会因百科永久失效；百科主要在玩家回合查看。

### 8.2 内容

百科使用 `Allies`、`Enemies` 两个标签页，读取单位 JSON，不硬编码条目。每个名称只显示一次，并包含：

- 当前圆形占位头像按英文单位名称显示首字母缩写，为后续正式头像保留 `sprite` 字段。
- 名称、近战/远程类型和职业。
- 生命、护盾、攻击、移动、射程和真实伤害，单位信息字段显示中文。
- 特殊属性；无则显示“无”。
- Ability 名称与完整效果；无则显示 `None`。

内容可滚动，在 1100x720 下无文字裁切或卡片嵌套。

## 16. 试玩反馈修订

### 16.1 Encyclopedia 单位信息中文化

- 保留 `Unit Encyclopedia`、`Back`、`Allies`、`Enemies` 等界面标题、导航和按钮英文。
- 保留单位名称英文，继续作为单位模板名和图标缩写来源。
- 单位卡片内与单位信息有关的字段中文化：类型、职业、生命、护盾、攻击、移动、射程、真实伤害、特殊属性和能力。
- `Melee/Ranged` 显示为“近战/远程”，`Soldier/Archer/Raider` 显示为“战士/弓手/掠夺者”。
- `Yes/No` 显示为“是/否”，`None` 显示为“无”，`Wood/Fire/Earth` 显示为“木/火/土”。
- 三项能力的 Encyclopedia 说明使用中文；战斗逻辑和能力 ID 不变。

### 16.2 单位图标名称缩写

- 棋盘与 Encyclopedia 使用同一名称缩写函数，不再按近战/远程固定显示 `M/R`。
- 单词名称取首字母，多个单词依次取首字母并转为大写，例如 Archer=`A`、Verdant Guard=`VG`、Earth Warden=`EW`。
- 名称中首词之后独立出现的 `man` 或 `woman` 不生成字母；`Marksman` 属于完整单词，图标仍为 `M`。
- 空名称回退为 `?`；双字母图标使用较小字号，必须完整容纳在圆形图标内。
- 新增 `UnitIconFormatter` 作为棋盘和图鉴的唯一缩写规则源。

### 16.3 AI 绕障与攻击位置规划

当前 AI 在本回合没有立即攻击位置时，不再仅以目标曼哈顿距离选择终点。

```text
已有合法目标 -> 直接攻击
否则计算本回合可达位置
-> 对每个候选位置搜索到任一合法攻击位置的最短战略路线
-> 优先选择剩余战略路线最短的位置
-> 移动后重新按原规则选择攻击目标
-> 所有合法攻击位置均不可达时，才回退到曼哈顿接近规则
```

- 合法攻击位置使用 `AttackRangeCalculator.can_attack_from()` 判定，包含近战 Cliff、远程射程和高度规则。
- 战略路线搜索遵守地图边界、Water/Mountain、Cliff 和普通地形代价。
- Swamp 在跨回合战略估价中使用最低进入移动力作为估算代价；本回合实际移动仍由 `MovementCalculator` 精确结算并清空剩余移动力。
- 玩家占据格不可穿越；友方 AI 占据格视为临时可穿越，但不能作为本回合停止位置。
- 即使候选格暂时增加与目标的曼哈顿距离，只要缩短实际合法攻击路线，AI 仍应选择该格。
- 即时攻击的低 HP、低护盾目标优先级、火属性倍率和其他战斗规则保持不变。
