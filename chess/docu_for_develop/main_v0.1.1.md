## 3. v0.1.1 版本目标

本版本在不扩大核心玩法范围的前提下，让玩家能够看清移动路径、鼠标所指对象、最近发生的战斗事件及敌方逐个行动过程。

完成后的战斗流程：

```text
选择单位
-> 悬停查看目标格与预计路径
-> 移动
-> 攻击或待机
-> 日志记录行动
-> 敌方单位逐个行动并显示反馈
-> 返回玩家回合或进入胜负结算
```

## 4. 本版本新增功能

### 4.1 战斗事件日志

| 条目 | 规则 |
|---|---|
| 显示位置 | 右侧 HUD 的战况区域 |
| 最大显示数量 | 最近 8 条 |
| 新日志位置 | 列表底部 |
| 战斗重开 | 清空旧日志并记录新战斗开始 |

必须记录：

- 回合开始。
- 单位移动。
- 单位攻击及 HP 或护盾变化。
- 单位待机。
- Victory 或 Defeat。

### 4.2 棋盘悬停信息

鼠标悬停在地图内时，HUD 显示：

- 格子坐标。
- 地形名称和高度。
- 基础移动消耗或不可通行状态。
- 该格存在单位时显示单位名称、阵营、类型、HP 和护盾。

悬停信息只用于查看，不改变当前选择和行动阶段。

### 4.3 移动路径预览

- 选中尚未移动的玩家单位后，悬停在可移动格时显示最小消耗路径。
- 路径只使用移动计算模块已经生成的父节点数据。
- HUD 同时显示路径总移动消耗。
- 鼠标离开可移动范围时清除路径预览。
- 不能为不可达格、占据格或不可通行格显示路径。

### 4.4 取消操作状态优化

| 当前状态 | 右键或 Esc 结果 |
|---|---|
| 攻击目标选择 | 返回该单位的移动或行动状态，保留单位选择 |
| 已移动后的行动状态 | 取消单位选择，单位移动结果不撤销 |
| 普通单位选择 | 取消单位选择 |
| 未选择状态 | 不执行操作 |

v0.1.1 仍不支持撤销已经完成的移动。

### 4.5 最近行动地图标记

- 移动完成后，短时间或直到下一次有效行动前显示移动路径线。
- 攻击完成后，标记攻击者与目标所在格，并绘制攻击连线。
- 单位死亡后目标格仍可保留一次攻击标记。
- 新战斗开始时清除全部最近行动标记。

### 4.6 敌方行动分步播放

- 敌人仍按单位 ID 顺序行动。
- 每个敌方单位行动后刷新棋盘、HUD 和日志。
- 相邻敌方单位行动之间默认间隔 `0.35` 秒。
- 敌方回合期间禁用玩家棋盘输入和行动按钮。
- 重新开始战斗时，旧回合的延迟任务不得继续修改新战斗。
- 自动化测试中允许将间隔设为 `0`，保证测试同步和快速执行。
