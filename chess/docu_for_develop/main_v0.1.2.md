## 3. v0.1.2 目标

本版本增加累计移动点与多次移动，建立启动前关卡选择，并加入一张内容更多的第二关。完成后，玩家可以在同一回合中分段调整位置，并在两张规则一致但地图规模和单位配置不同的关卡之间选择。

目标流程：

```text
启动游戏
-> 进入关卡选择
-> 选择第一关或第二关
-> 进入战斗
-> 选择单位
-> 使用 Move 按钮或直接点击可达格
-> 在剩余移动点内继续分段移动
-> 攻击或待机
-> 完成敌方回合与胜负结算
-> 重试当前关卡或返回关卡选择
```

## 4. 累计移动点系统

### 4.1 新增运行时状态

每个单位增加：

| 字段 | 类型 | 说明 |
|---|---|---|
| `remaining_move_points` | int | 当前回合剩余移动点 |
| `move_spent_this_turn` | int | 当前回合累计消耗移动点 |

回合开始时：

```text
remaining_move_points = move_range
move_spent_this_turn = 0
has_moved = false
has_acted = false
```

`has_moved` 继续表示本回合是否发生过至少一次移动，但不再作为禁止继续移动的条件。

### 4.2 分段移动规则

- 单位一回合可以移动零次、一次或多次。
- 所有移动段的累计消耗不能超过单位基础移动力。
- 每次移动完成后立即扣除该段实际路径消耗。
- 下一次移动范围从当前位置计算，预算使用剩余移动点。
- 移动点不能恢复，也不能通过往返移动重复使用。
- 剩余移动点为 0 时不能继续移动。
- 攻击或待机后单位结束行动，未使用的移动点作废。
- 手动结束回合时，所有未使用移动点作废。
- v0.1.2 仍不支持撤销已完成的移动。

高度不再参与移动消耗。普通地形和边界的单步消耗为：

```text
单步消耗 = 目标地形基础消耗 + 边界额外消耗
```

| 目标地形 | 进入条件 | 进入消耗 |
|---|---|---|
| 平地 | 剩余移动力至少 1 | 1 |
| 森林 | 剩余移动力至少 2 | 2 |
| 沼泽 | 剩余移动力至少 2 | 消耗全部剩余移动力 |
| 水域 | 不可进入 | 不适用 |
| 山体 | 不可进入 | 不适用 |

- 河流边界继续额外消耗 1 点移动力。
- 进入平地或森林时，必须同时支付目标地形消耗和河流额外消耗。
- 进入沼泽时先检查剩余移动力至少为 2，成功进入后剩余移动力直接变为 0；跨河进入沼泽也不会产生负数或额外欠费。
- 悬崖边界继续不可通过。
- 从高处移动到低处、从低处移动到高处均不产生高度差消耗。

### 4.3 Move 按钮

现有操作区由四个按钮调整为五个顶层按钮：

```text
Move        Attack
Wait        End Turn
Menu
```

`Menu` 打开选项菜单，菜单内提供 `Restart` 和 `Levels`，并为未来设置、帮助或退出等选项保留扩展位置。Restart 和 Levels 不再作为独立顶层按钮显示。

Move 按钮规则：

- 已选择、未行动且剩余移动点大于 0 时可用。
- 点击后进入 `move` 状态并显示当前剩余移动点可到达的范围。
- 已经移动过的单位仍可通过 Move 按钮继续移动。
- 处于攻击目标选择时点击 Move，返回移动状态并清除攻击范围。
- 敌方回合、战斗结束、单位已行动或剩余移动点为 0 时禁用。

### 4.4 保留直接点击移动

- 选择尚未行动且有剩余移动点的玩家单位时，默认直接显示移动范围。
- 玩家可以不点击 Move，直接点击高亮可达格完成移动。
- 一段移动后继续保持该单位选中，并重新显示剩余移动范围。
- 玩家可以继续直接点击下一可达格，也可以使用 Move 按钮重新进入移动状态。
- Attack 或 Wait 可在任意一次合法移动后执行。
- 敌方 AI 仍可一次计算并移动到最终目标格，不要求拆成多个玩家式移动操作；其总消耗同样不得超过基础移动力。

### 4.5 移动 UI

单位信息新增：

```text
Move       剩余值 / 基础值
Spent      本回合累计消耗
```

悬停可达格时继续显示该段路径成本，并增加移动后的预计剩余值。

战斗日志每段移动单独记录：

```text

```

## 5. 关卡选择系统

### 5.1 启动状态

- 游戏启动后不再立即进入第一关。
- 首屏为实际可操作的关卡选择界面，不增加营销页或复杂主菜单。
- 第一关和第二关从开始时均可选择，不设置解锁或存档条件。

每个关卡条目显示：

- 关卡编号与名称。
- 地图尺寸。
- 玩家与敌方单位数量。
- 主要地形。
- 难度标记。
- `Deploy` 命令。

### 5.2 战斗内关卡操作

- 点击 `Menu` 打开或关闭战斗菜单。
- 菜单中的 `Restart` 重新加载当前关卡。
- 菜单中的 `Levels` 返回关卡选择界面。
- 返回关卡选择时丢弃当前战斗进度。
- 返回关卡选择和重新开始都必须使旧敌方异步回合失效。
- Victory 或 Defeat 后仍可重试当前关卡或返回关卡选择。
- 打开 Menu 时暂停棋盘指令输入；关闭 Menu 后恢复到打开前的选择和行动状态。
- 敌方回合和胜负结算状态也允许打开 Menu，以便 Restart 或返回 Levels。

### 5.3 关卡目录数据

新增：


关卡目录建议字段：

## 8. 动态棋盘尺寸

v0.1.1 棋盘视图使用固定 `BOARD_SIZE = 10`；v0.1.2 已按以下方式改为动态尺寸：

- 绘制尺寸读取 `controller.grid.width` 和 `controller.grid.height`。
- Tile 大小根据棋盘控件可用宽高和地图尺寸计算。
- 10x10 与 12x12 地图都保持居中。
- 悬停坐标、边界线、路径、单位和高亮均使用动态 Tile 大小。
- 1100x720 下 12x12 棋盘与右侧 HUD 必须完整可见。
- 不使用随视口变化的字体大小，避免布局跳动。

### 8.1 高度与攻击规则

高度字段和地图高度显示继续保留，但高度只参与远程攻击资格判断：

- 近战攻击不受高度影响，仍要求曼哈顿距离为 1，并受悬崖边界阻挡。
- 远程攻击不再因高差增加或减少射程。
- 远程攻击距离始终使用单位基础 `attack_range`。
- 远程单位只能攻击所在地形高度不高于自身所在地形高度的敌方单位。
- 目标与攻击者同高时可以远程攻击。
- 目标高于攻击者时不能远程攻击。
- 远程攻击仍可跨越悬崖，但必须同时满足基础射程和目标高度不高于攻击者的条件。

```text
远程可攻击 = 曼哈顿距离 <= attack_range
          且 目标地形高度 <= 攻击者地形高度
```

AI 远程单位在当前无法攻击时，应优先选择移动后能够形成合法高打低攻击的位置，再按原有接近目标规则选择位置。

## 12. 状态机实际调整

实际状态：

```text
level_select
select
move
attack
action
inspect
enemy
finished
```

玩家单位流程：

```text
select
-> move
-> 一次移动
-> move（仍有移动点）/ action（移动点耗尽）
-> move / attack / wait
-> select
```

规则优先级：

1. `has_acted == true` 时禁止移动与攻击。
2. `remaining_move_points <= 0` 时禁止进入移动状态。
3. 攻击或待机立即结束单位行动。
4. 是否移动过不再决定能否继续移动。

## 18. 风险与控制

| 风险 | 控制措施 |
|---|---|
| 多次移动绕回造成移动点错误 | 每段按实际最小路径成本立即扣除，不根据位移距离估算 |
| 新单位进入第一关 | 控制器按当前关卡出生点实例化，不遍历生成全部定义 |
| 12x12 地图超出窗口 | 棋盘按地图宽高动态计算 Tile 大小并做图形截图检查 |
| 切换关卡时旧 AI 继续运行 | 复用并扩展 `battle_generation` 保护 |
| 两关数据校验只覆盖第一关 | 测试逐关加载并分别执行完整数据校验 |
| Move 与直接点击状态冲突 | 两种入口统一调用控制器的 `request_move()` 与移动执行接口 |
| Move 和 Menu 挤压 HUD | 使用紧凑固定尺寸命令区，Restart/Levels 收入 Menu |
| 沼泽消耗依赖剩余点，普通 Dijkstra 权重不足 | 搜索时携带当前累计成本；沼泽作为消耗完全部预算的终点，不从该节点继续扩展 |
| 远程单位无法低打高 | 两关提供可到达森林高地，远程 AI 优先评估移动后合法攻击位置 |
